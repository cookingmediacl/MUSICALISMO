# Musicalismo

Sitio web de Musicalismo junto a Caja Los Andes.

## Cómo subirlo a GitHub

Todos los archivos van sueltos en la raíz del repositorio, sin carpetas.

1. En el repositorio, toca **Add file → Upload files**.
2. Arrastra **todos** los archivos de esta carpeta (no la carpeta) y toca **Commit changes**.
3. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.

## Qué hay

- `index.html`: la página completa.
- `intro-loop.mp4`, `intro-poster.jpg`: loop de la apertura.
- `backstage.mp4`, `backstage-poster.jpg`: montaje que se ve al entrar.
- `fondo.m4a`: música de fondo.
- `photocall.jpg`, `lanzamiento.jpg`, `displays.jpg`, `cuadro10.jpg`, `cuadro20.jpg`, `cuadro24.jpg`: vitrina de Caja Los Andes.

## Editar

En `index.html`, busca el bloque **Edita aquí**: `LETRAS` (karaoke), `FECHAS` (próximas funciones) y `AUDIO`.
El volumen de la música está en `const VOLUMEN=0.15`.
